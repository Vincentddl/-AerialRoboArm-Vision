FoamBoardTracker EXE 使用说明
============================

一、直接启动

1. 必须先完整解压 ZIP，不能在压缩包预览窗口里直接运行。
2. 连接摄像头。
3. 双击 FoamBoardTracker.exe。
4. 按 Q 或 Esc 退出检测窗口。

不需要安装 Python、PyTorch 或 CUDA Toolkit。
如果电脑有 NVIDIA 显卡，请先安装较新的 NVIDIA 显卡驱动。

二、角度信息

axis_offset：
物体与摄像头连线相对相机光轴的当前三维夹角。

axis_offset@+0.4s：
预测 0.4 秒后的光轴偏移角。

光轴中心为 0°，物体向任意方向偏离时角度增大。
OK 表示预测有效，INVALID 表示当前预测不宜用于控制。

三、关于数据集和模型

实时运行不直接读取数据集，而是读取已经训练完成的模型权重：

_internal\models\foam_board_2p1mm_v7.pt

如果只有数据集，仍需使用源码和 Python 环境训练得到 .pt 权重。
如果已经有兼容的泡沫块 .pt 权重，可以备份原文件，然后用新权重替换上述文件并保持文件名不变。

四、相机标定

_internal\configs\camera_2p1mm_640x480_fisheye.json

该标定文件只对原摄像头、镜头和 640×480 分辨率准确。
换摄像头、镜头、焦距或分辨率后，必须重新标定才能保证偏移角准确。

五、注意事项

1. 不要只复制 FoamBoardTracker.exe；必须连同 _internal 文件夹一起发送。
2. 不要移动或删除 _internal 里的 DLL、模型和配置文件。
3. Windows 或杀毒软件可能对未签名的自制 EXE 给出提示，可先进行病毒扫描再选择运行。
4. 首次启动会初始化模型和 CUDA，速度比后续帧慢。
