泡沫块实时检测与 0.4 秒轨迹预测
==================================

一、推荐环境

1. Windows 10/11 64 位。
2. Python 3.9 64 位。
3. NVIDIA 显卡用户先安装最新显卡驱动。
4. 摄像头支持 640×480 分辨率。

二、首次安装

有 NVIDIA 显卡：
双击 INSTALL_GPU.bat，等待 PyTorch CUDA 版和项目依赖安装完成。

没有 NVIDIA 显卡：
双击 INSTALL_CPU.bat。CPU 模式可以运行，但实时速度会明显降低。

安装过程需要联网，下载 PyTorch 可能需要较长时间。

三、启动

连接摄像头后双击 RUN_PROJECT.bat。
程序默认打开编号 0 的摄像头。
按 Q 或 Esc 退出检测窗口。

红色角度文字：

axis_offset：物体与摄像头连线相对相机光轴的当前三维夹角。
axis_offset@+0.4s：预测 0.4 秒后的光轴偏移角。
光轴中心为 0°，向任意方向偏离时角度增大。
OK 表示预测有效，INVALID 表示当前预测不宜用于控制。

四、检查 GPU

双击 CHECK_ENVIRONMENT.bat。
如果显示 CUDA available: True，并显示显卡名称，说明正在使用 GPU。

五、重要说明

1. configs\camera_2p1mm_640x480_fisheye.json 是原摄像头的鱼眼标定文件。
2. 换用另一颗摄像头、镜头、焦距或分辨率后，偏移角可能不准确，必须重新标定。
3. 模型主要使用原拍摄环境训练。朋友所在环境、光线或泡沫块外观差异较大时，识别效果可能下降。
4. 不要删除 models、configs、scripts 或 tracking 文件夹。
