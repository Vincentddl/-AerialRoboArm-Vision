# 实时角度程序分类

## 1. 实测舵机标定模式（当前推荐）

入口：`scripts/run_foam_board_servo_calibrated.py`

该模式加载 `configs/servo_to_optical_angle_yolo_v8_20260804_v1.json`。该关系专门使用 YOLO V8 边界框中心拟合，与实时程序采用的目标锚点一致。实时画面和 JSON 输出明确区分：

- `optical_axis_offset_deg`：目标相对镜头光轴的单轴偏移角，向画面下方为正。
- `servo_command_deg`：根据 2026-08-04 实测素材反算的舵机 `g` 指令角。
- `legacy_mechanical_angle_deg`：旧定义，等于光轴偏移角加镜头安装倾角。
- `lateral_angle_deg`：目标相对机械臂运动平面的左右偏角，只用于判断能否抓取。

实测关系仅在 `g=-95°` 至 `g=-45°` 范围内有效。超出范围时程序保留数值用于观察，但将 `servo_calibration_valid` 和 `target_valid` 标记为 `false`，不应直接用于控制。

配置允许 `0.75°` 的边界容差，用于吸收线性拟合残差和检测框抖动；JSON 会同时输出原始拟合范围和边界容差，不会隐藏外推范围。最初按人工泡沫块中心得到的关系仍保存在 `configs/servo_to_optical_angle_20260804_v1.json`，作为离线分析参考，不用于当前 YOLO 实时入口。

机械传动按舵机40齿、从动齿轮48齿记录，即从动齿轮角度增量为舵机角度增量的 `-40/48`。该传动效果已经自然包含在实测关系中，实时换算不会再次乘齿轮比。由于尚未定义从动齿轮的机械绝对零位，当前不输出容易误解的绝对 `gear_output_angle_deg`。

该入口单独使用 `conf=0.10` 和 `new-track-conf=0.10`，并继续要求连续两帧确认。旧入口仍保留原来的较严格阈值。当前 V8 模型在本次素材的 `-65°` 至 `-95°` 区段检测较稳定，而 `-45°` 至 `-60°` 的检测分数仍偏低；角度关系已写入，但完整视野覆盖还需要后续补充数据训练检测模型。

## 2. 旧版几何角度模式（保留）

入口：`scripts/run_foam_board.py`

该模式不加载舵机实测关系，继续使用原来的鱼眼像素到视线角换算，并保留 `arm_angle_deg` / `offset_angle_deg` 作为相对机械水平轴的旧角度字段。旧程序、旧模型和可选预测代码均未删除。

## 共同部分

两个入口都使用同一套 YOLO 泡沫块检测、目标确认/跟踪以及鱼眼相机标定。当前默认 `target-mode=current`，不预测 0.4 秒后的目标位置。
